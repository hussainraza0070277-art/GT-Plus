## 🚀 What Is GT-Plus?

GT-Plus takes that power further by giving you a dedicated, cross-platform editor that works on Windows, macOS, and Linux.

Think of it this way: vMix gives you a toolbox. GT-Plus gives you the entire workshop.

## 🛠️ Getting Started

### 📂 Opening a Template

1.  Launch GT-Plus.
2.  Click **File** in the top menu.
3.  Select **Open**.
4.  Navigate to your `.gtzip` file and select it.
5.  Click **Open**. Your title will appear in the editor.

### 🎨 Making Edits

- **Select an element** by clicking it directly in the preview area.
- **Change properties** using the panel on the right side of the window.
- **Adjust text** by clicking on the text element and typing.
- **Move elements** by dragging them with your mouse.
- **Resize elements** by dragging the corner handles.

### 💾 Saving Your Work

- **File › Save** will save your changes back to the original `.gtzip` file.
- **File › Save As** lets you save a copy with a new name. This is useful when you want to keep the original intact.

No. GT-Plus is completely standalone. You only need the `.gtzip` files, which you can get from vMix or create from scratch.

Yes. GT-Plus saves files in the standard `.gtzip` format, so vMix will read them perfectly. Your edited titles will work exactly as expected.

## 🧑‍💻 For Advanced Users

If you're comfortable with the command line, GT-Plus offers additional control:

### 🏃 Running in Development Mode

```bash
cd src/GtPlus
dotnet run
```

This requires the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) or newer.

### 📦 Building Release Binaries

From the repository root, run the build script:

```powershell
./build.ps1
```

### ⚙️ Build Options

| Command | Effect |
| --- | --- |
| `./build.ps1` | Bump patch, build all platforms |
| `./build.ps1 -Bump Minor` | Bump minor (patch resets to 0) |
| `./build.ps1 -Bump Major` | Bump major (minor and patch reset to 0) |
| `./build.ps1 -Bump None` | Rebuild the current version in place |
| `./build.ps1 -SetVersion 1.0.0` | Build an exact version |
| `./build.ps1 -Rid win-x64` | Build a subset of platforms |
| `./build.ps1 -NoA` | Build without architecture-specific optimizations |
